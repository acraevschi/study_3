# GeLaTo link review sheets (2026-10-09)

## `unresolved_populations.csv`

One row per GeLaTo population link that the typology stage (pcfp_v2) could not attach to a
language-level Glottocode. Generated by `make_unresolved_sheet.py`, which reads population
metadata only; no ancestry file is opened.

`issue` values:

| issue | meaning |
|---|---|
| `group_ambiguous` | the population's Glottocode is a group with several Grambank-coded languages (`candidates`) |
| `group_no_grambank_descendant` | its Glottocode is a group with no Grambank-coded language |
| `unresolved` | it has no Glottocode (NA in GeLaTo and Table S1), or one not in Glottolog 5.3 |

Context columns:

* `own_glottocode`, `candidates`, `graff_gbi_proxy`, `graff_tli_proxy`: Glottocode with
  Glottolog name and level, and "in Grambank" where it has a Grambank entry. The proxies
  are the Graff et al. 2025 curators' choices (Table S1).
* `other_links_of_population`: links the population already has through a proxy. Such
  populations are not lost, but proxies stay out of the main analysis.
* Place, coordinates, reference, and GeLaTo and Graff curation comments.

Rows are sorted by issue, then by number of individuals.

**To fill in:**

| column | value |
|---|---|
| `FILL_decision` | `link`, `exclude` or `unsure` |
| `FILL_glottocode` | the language-level Glottocode to link (for `link`) |
| `FILL_link_type` | `exact` (the population speaks this language), `dialect` (it speaks a dialect of it), `best_guess` (a group or mixed population assigned to its most likely language) |
| `FILL_reason` | short reason |
| `FILL_sources_consulted` | e.g. the original genetics paper, Glottolog, the sampling location |
| `FILL_confirmed_by`, `FILL_confirmed_date` | your name and the date (YYYY-MM-DD); a row without them is not used |

A filled row is used only after it is read back into the pipeline as a manual link (not
wired yet). Re-running the script refuses to overwrite a sheet that has any `FILL_*` cell
filled.
