# GeLaTo link review sheets (2026-10-16)

**Superseded on 2026-10-20.** Decisions now go into one sheet,
`morph_ldl/data/gelato_link_review.csv` (`docs/TYPOLOGY.md` §2). The sheets here stay as
evidence; the source check (`provenance_check.csv`) supplied the `wrong_code` labels there.

Generated by `make_sheets.py` from `outputs/pcfp_v2_review_2026_10_16/typology/` (the rerun
under the review rule of 2026-10-16) and population metadata only. No ancestry file is
opened.

## `main_set_links.csv`

The 294 links of the main Grambank analysis: every non-proxy, non-excluded link whose
language is in the main set (175 languages: Grambank entry, coverage ≥ 60%). 250 exact,
33 dialect roll-ups, 11 group map-downs. The 7 Scottish links (to Scottish Gaelic, outside
the main set) are added at the end of the review block (`in_main_set = False`), because a
different link would bring them in. 301 rows; rows that require review come first.

Columns:

* the link: `population`, `n_individuals`, `language_name`, `glottocode`,
  `own_glottocode` (GeLaTo's code, with its Glottolog name) and its level, `link_basis`,
  `in_main_set`;
* `review`: `requires review`, or empty;
* `comment`: why the row requires review, how the link was made (dialect roll-up, group
  map-down), the Glottolog endangerment status, any agent review proposal, and the
  pipeline's own notes (for example small samples);
* `decision`: empty, for the reviewer;
* evidence: place, country, coordinates, genetics reference, GeLaTo curation note.

**How rows are marked `requires review`** (64 rows, 57 in the main set):

* **By hand (47 rows, `manual_flags.csv`).** Each of the 294 links was read once
  (population, place, language). Rows were marked where the sampled people probably
  speak a different language from the linked one:
  * regional samples whose traditional language differs from what people speak today
    (Bergamo, French regions, Irish, Scottish, Basque, Catalan, Galician, Georgian in
    Megrelia);
  * language shift (Malawi_Ngoni, Chané, She, Hezhen, Tujia, Aleut on Bering Island);
  * diaspora samples (Jewish communities sampled in Israel);
  * group map-downs that picked the coded language, not the spoken one (Mixe, Sardinian,
    Pathan, Tu);
  * codes that point to a different language from the one the place suggests (Cypriot →
    Cypriot Maronite Arabic, Kaitag, two Yemeni regions, two Guarani groups, Han,
    Taiwan Han, Mbuti, Kharia).

  Each reason is one line in `manual_flags.csv`. This is a judgement from population
  metadata and general knowledge, not a check of the original genetics papers.
* **By rule (17 more rows).** The linked language is moribund, nearly extinct or extinct
  in Glottolog 5.3 (agglomerated endangerment status, AES ≥ 4), so most of the sampled
  community probably speak another language (for example Nganasan, Negidal, Ulch,
  Veps). Languages that are only "shifting" (AES 3) get a comment, not
  a mark.

Not marked: dialect roll-ups and group map-downs that look right (the comment says how
the link was made), first-generation migrants sampled in Kuwait (Egyptian2, Jordanian,
Lebanese), and Iranian_Bandari (Bandari is a dialect of Western Farsi in Glottolog).
Unmarked rows are the ones meant for acceptance in one step.

A filled `decision` is not read by the pipeline yet. Decisions take effect only through
`morph_ldl/data/gelato_review.yaml` (status + `confirmed_by` + `confirmed_date`).

## `group_populations_to_review.csv`

The 29 `group_ambiguous` rows of `analyses/gelato_review_2026_10_09/unresolved_populations.csv`,
unchanged, with the same `FILL_*` columns. Each population's GeLaTo code is a group with
several Grambank-coded languages (for example Greek, Mongolian, Loloish/Yi, Ojibwa). If a
population is linked to one of them, it enters the analysis. For 10 of the 29, a candidate
language is already in the main set.

**Scope decision (user, 2026-10-16).** Only these 29 of the 69 unlinked populations are
reviewed. The other 40 are not reviewed:

* 35 `unresolved`: no usable Glottocode (for example New_Guinea_Highlander, Papuan,
  AfroAmericans_Denver, Iranian migrants sampled in Kuwait);
* 5 `group_no_grambank_descendant`: the group has no Grambank-coded language (for
  example Sorbian, Luri, Luhya).

They need no exclusion in the data. They have no language link, so they enter no outcome
row. Three of them have a TLI stand-in link (Iranian_Lor → Bakhtiari, German_Sorb → Upper
Sorbian, Luhya → Tsotso), but none of these stand-in languages has Grambank data, so they
add nothing either, not even to proxy sensitivity analyses. They remain in the link
tables, as `unmatched`. Revisit them only if languages are hand-coded from grammars.

## `provenance_check.csv` and `PROVENANCE.md`

A source check of the 64 `requires review` rows (2026-10-16): for each population, what
the original genetics paper says about sampling site and community, and which language
the sampled people most likely speak today. `PROVENANCE.md` summarises it; its note at the
top corrects the first version on three French rows. Among the findings: the two Yukaghir
samples carry each other's codes in GeLaTo and in Table S1 of Graff et al. 2025.
